# college-finder

College Finder is a web application designed to help students search for colleges across India and explore the courses they offer. The goal is to simplify the college selection process through a user-friendly interface and efficient search functionality.

 Click Here to Checkout Website:https://sahadudeen.github.io/college-finder/
 
  eg: search college "IIT DELHI".


## Features

-  Search colleges by name
-  View detailed information about a selected college
-  Explore courses offered by each college
-  Display a full-screen image of the selected college
-  Mobile responsive design
-  Connected with Node.js and MySQL for backend and data storage

---

##  Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js  
- **Database:** MySQL  
- **Other:** Express.js, Bootstrap (optional), and other open-source libraries

##  How to Run the Project

1. **Clone the Repository**
2. 
   git clone https://github.com/yourusername/college-finder.git
   cd college-finder
   
# Install Dependencies
npm install

# Setup MySQL Database

Import the SQL file database.sql into your MySQL server

Update database connection settings in server.js or .env file

# Start the Server
node server.js

run the code
